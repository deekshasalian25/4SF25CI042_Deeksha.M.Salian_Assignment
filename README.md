# Pandas Assignment

## Overview
This repository contains Python programs implemented using the Pandas and NumPy libraries. The assignment focuses on basic DataFrame operations, data manipulation, aggregation, merging, MultiIndex operations, applying functions, and working with text data.

## Topics Covered

1. Creating DataFrames and adding new columns.
2. Row-wise and column-wise sum.
3. Handling missing values using `fillna()` and column mean.
4. Removing rows containing missing values using `dropna()`.
5. Data aggregation using `groupby()`, `sum()`, and `mean()`.
6. Grouping product sales by category.
7. Merging two DataFrames.
8. Creating MultiIndex DataFrames and performing indexing and slicing.
9. Grouping data using Category and SubCategory.
10. Applying functions to DataFrames.
11. Using lambda functions to calculate row-wise sums.
12. Converting strings to uppercase.
13. Extracting the first three characters from strings.

## Libraries Used

- Python
- Pandas
- NumPy
